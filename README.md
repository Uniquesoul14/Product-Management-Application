

<h1>🛍️ Product Management System</h1>

A React-based Product Management System that allows users to manage products efficiently with full CRUD functionality, powered by Redux Toolkit and JSON Server as the backend API. Perfect for practicing state management, API integration, and dynamic UI updates! ✨

<h2>⚡ Features</h2>
📝 CRUD Functionality<br>

📦 Fetch All Products (GET): Retrieve and display all products from the JSON Server.<br>

➕ Add Product (POST): Add new products through a form with fields: title, category, price.<br>

✏️ Update Product (PUT): Edit and update existing product details.<br>

🗑️ Delete Product (DELETE): Remove products from the system.<br>

🧩 State Management: All state is handled using Redux Toolkit for a centralized, predictable workflow.

<h2>🔍 Search & Filter</h2>

🔎 Search: Search products by title.<br>

📂 Filter: Filter products by category.<br>

💡 Combined Functionality: Search and filter work together to quickly find any product.

<h2>🌐 Backend Integration</h2>

All product data is stored and updated in a JSON Server API, enabling persistent changes across sessions.

<h2>🚀 Usage</h2>
<h4>
1.Clone the repository.</h4><br>

<h4>2.Install dependencies:<br>

  npm install<br>


<h4>3.Start JSON Server:</h4>

json-server --watch db.json 


<h4>4.Start the React app:</h4>

npm start

<h2>
Open the app at http://localhost:3000 🌐</h2>
